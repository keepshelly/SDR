# Работа с буфером: получение цифровых IQ-отсчётов. Приём-передача сэмплов на 2 SDR

Реализовал передачу с одной SDR на другую:

- TX1 — 810 МГц
- RX1 — 820 МГц
- TX2 — 820 МГц
- RX2 — 810 МГц

Записал принятые данные (комплексные IQ-отсчёты) в файл `rxdata.pcm` и построил графики с помощью Python-скрипта.
