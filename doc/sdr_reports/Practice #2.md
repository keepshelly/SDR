# Работа с буфером: получение цифровых IQ-отсчётов. Приём-передача сэмплов на 2 SDR

Реализовал передачу с одной SDR на другую:

- TX1 — 810 МГц
- RX1 — 820 МГц
- TX2 — 820 МГц
- RX2 — 810 МГц

Записал передаваемые данные(i and q  комплексные отсчеты) в файл rxdata.pcm и сделал вывод на график через python скрипт
